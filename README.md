# 🏠 Sistema Imobiliário
### Desafio PMSL
Sistema simples de cadastro de imóveis e proprietários em PHP e MySQL.

---

## 📌 Funcionalidades

* Cadastro de proprietários
* Cadastro de imóveis
* Associação de imóvel com proprietário
* Listagem de dados
* Edição e exclusão de registros

---

## ⚙️ Tecnologias utilizadas

* PHP
* MySQL
* HTML
* XAMPP

---

## ▶️ Como executar o projeto

Siga os passos abaixo para rodar o sistema na sua máquina:

### 1. Instalar o XAMPP

Baixe e instale o XAMPP:
https://www.apachefriends.org/

---

### 2. Iniciar os serviços

Abra o XAMPP e inicie:

* Apache
* MySQL

---

### 3. Colocar o projeto na pasta correta

Copie a pasta do projeto para:

C:\\xampp\\htdocs

---

### 4. Criar o banco de dados

1. Acesse o site:
   http://localhost/phpmyadmin

2. Clique em **Novo**

3. Crie um banco com o nome:
   imobiliaria

---

### 5. Importar o banco

1. Clique no banco criado (`imobiliaria`)
2. Vá na aba **Importar**
3. Clique em **Escolher arquivo**
4. Selecione o arquivo:
   banco.sql
5. Clique em **Executar**

---

### 6. Executar o sistema

No navegador, acesse:

http://localhost/NOME-DA-PASTA

Exemplo:
http://localhost/sistema-imobiliario

---

### Configuração do banco

Caso necessário, ajuste os dados no arquivo `conexao.php`.
